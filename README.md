## 我如何构建 / How I build

- 先把问题做成可走通的 Demo，再扩展功能边界。
- AI 可以参与生成和检索，但来源、失败与降级状态必须对用户诚实。
- 让人保留关键选择权：系统提供结构与反馈，不替用户作判断。
